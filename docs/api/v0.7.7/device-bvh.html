common_prefix(const int num_objects, const uint32_t *morton_codes, const int i, const int j) -> int

Length of the common high-order bit prefix of two Morton codes.

The similarity measure Karras's hierarchy construction is built on: the longer the shared prefix, the closer two primitives lie in space. Equal codes fall back to comparing indices, which breaks ties deterministically and keeps the emitted tree well-formed when several primitives share a cell.

Parameters
NameDescription
num_objects[in] Number of primitives, used for the bounds check.
morton_codes[in] Device array of sorted Morton codes.
i[in] First index.
j[in] Second index; out-of-range values return $-1$ to terminate a range scan.
Returns
__device__ __forceinline__ int
