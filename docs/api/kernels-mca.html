compute_active_voxels_mca_kernel(const uint32_t num_voxels, const uint32_t *voxels, const float *sdf, const float iso, uint32_t *triangle_counts) -> void

Counts the triangles each voxel emits, resolving ambiguous faces on the fly.

Sizing pass. One thread per voxel. Unambiguous cases read their triangle count straight from the Marching Cubes tables; cases flagged by cubeFaceAmbigMask evaluate the bilinear saddle on each ambiguous face and pick the connection its sign implies. Because both cells sharing a face compute the same saddle value, neighbours always agree and the surface cannot crack the defect plain Marching Cubes exhibits on these cases.

Parameters
NameDescription
num_voxels[in] Number of voxels.
voxels[in] Device array of eight corner indices per voxel.
sdf[in] Device array of scalar field values at grid vertices.
iso[in] Isolevel separating inside from outside.
triangle_counts[out] Device array of per-voxel triangle counts.
Note

Launched with NTHREADS threads per block over a 1D grid.

generate_edges_and_triangles_mca_kernel__global__#conquer3d/csrc/ops/mca.cu:272
generate_edges_and_triangles_mca_kernel(const uint32_t num_voxels, const uint32_t *voxels, const float *sdf, const float iso, const uint32_t *tri_offsets, uint64_t *out_edges, int3 *out_triangles) -> void

Emits triangles and their bipolar edge keys at precomputed offsets.

One thread per voxel, repeating the decider decisions from the counting pass so both agree exactly. Triangles are written as edge keys rather than vertex indices, to be remapped once the keys have been deduplicated; writes go to prefix-summed offsets and so need no atomics.

Parameters
NameDescription
num_voxels[in] Number of voxels.
voxels[in] Device array of eight corner indices per voxel.
sdf[in] Device array of scalar field values at grid vertices.
iso[in] Isolevel separating inside from outside.
tri_offsets[in] Device array of per-voxel triangle write offsets.
out_edges[out] Device array of 64-bit edge keys, three per triangle.
out_triangles[out] Device array of triangles, initially indexed by edge instance.
Note

Launched with NTHREADS threads per block over a 1D grid.

Warning

The decider must reach the same conclusion as the counting pass. Any divergence between the two for instance from a differently rounded saddle evaluation would overrun the allotted output range.

remap_triangles_kernel__global__#conquer3d/csrc/ops/mca.cu:374
remap_triangles_kernel(const uint32_t num_triangles, const uint32_t *edge_indices, int3 *triangles) -> void

Rewrites triangle indices from edge instances to deduplicated vertices.

One thread per triangle, substituting each of its three edge-instance slots for the unique vertex index found by the host's sort-and-unique pass. This is the step that welds the mesh: triangles from neighbouring voxels come to share vertices instead of duplicating them.

Parameters
NameDescription
num_triangles[in] Number of triangles.
edge_indices[in] Device array mapping edge instances to unique vertex indices.
triangles[inout] Device array of triangles, remapped in place.
Note

Launched with NTHREADS threads per block over a 1D grid.

interpolate_vertices_and_features_kernel(const uint32_t num_edges, const uint64_t *unique_edge_keys, const float3 *grid_vertices, const float *sdf, const float *in_colors, const int num_color_channels, const float iso, float3 *out_vertices, float *out_colors) -> void

Places one output vertex on each unique bipolar edge.

One thread per unique edge. The 64-bit key is unpacked into its two grid vertex indices and the crossing is interpolated linearly, with colours following the same parameter. Each edge is visited once, so no atomics are needed.

backward_dmca_kernel(const uint32_t num_edges, const uint64_t *unique_edge_keys, const float3 *grad_vertices, const float *grad_colors, const float3 *grid_vertices, const float *in_colors, const int num_color_channels, const float *sdf, const float iso, float *grad_sdf, float *grad_in_colors) -> void

Backpropagates vertex gradients into the scalar field and colours.

The analytical adjoint of the interpolation pass. One thread per unique edge, applying the closed-form derivatives of $t = (\text{iso} - f_0) / (f_1 - f_0)$ with respect to both corner values.
