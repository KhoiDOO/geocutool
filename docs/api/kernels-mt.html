compute_active_tets_kernel__global__#conquer3d/csrc/ops/mt.cu:108
compute_active_tets_kernel(const uint32_t num_tets, const uint32_t *tets, const float *vert_values, const float iso, uint8_t *tet_codes) -> void

Classifies every tet by the sign pattern of its four corners.

Stage 1 of extraction. One thread per tet; each compares its corner values against the isolevel and packs the results into a 16-case code. The code alone determines the tet's surface topology, so all later stages are table lookups rather than searches. Inactive tets entirely inside or outside receive code 0 and are compacted away by the host before stage 2, which is what makes cost scale with surface area rather than volume. A tetrahedron has only 16 cases and none of them is ambiguous, which is why Marching Tetrahedra needs no asymptotic decider and cannot produce cracks.

Parameters
NameDescription
num_tets[in] Number of tets.
tets[in] Device array of corner indices, four per tet.
vert_values[in] Device array of scalar field values at the grid vertices.
iso[in] Isolevel separating inside from outside.
tet_codes[out] Device array of one sign code per tet.
Note

Launched with NTHREADS threads per block over a 1D grid.

compute_active_edges_kernel__global__#conquer3d/csrc/ops/mt.cu:148
compute_active_edges_kernel(const uint32_t num_active_tets, const uint32_t *tets, const uint32_t *used_tet_index, const uint8_t *used_tet_codes, Edge *active_edges) -> void

Emits the bipolar edge keys of every active tet.

Stage 2. One thread per active tet, writing an Edge key the sorted pair of grid vertex indices for each edge the surface crosses. Keys are deliberately emitted with duplicates: an edge shared by several tets produces one key per tet, and the host then sorts and uniques them. Deduplicating this way welds the mesh, so a vertex on a shared edge exists exactly once and the result is watertight rather than a soup of unconnected tet patches.

Parameters
NameDescription
num_active_tets[in] Number of active tets after compaction.
tets[in] Device array of corner indices, four per tet.
used_tet_index[in] Device array mapping compacted index to original tet index.
used_tet_codes[in] Device array of sign codes for the active tets.
active_edges[out] Device array receiving the emitted edge keys, with duplicates.
Note

Launched with NTHREADS threads per block over a 1D grid.

Note

Uses the tetEdgeTable / tetTriTable table to look up which edges a case activates.

build_edge_map_kernel(const uint32_t num_active_tets, const uint32_t num_unique_edges, const uint32_t *tets, const uint32_t *used_tet_index, const uint8_t *used_tet_codes, const Edge *unique_edges, uint32_t *tet_edge_to_vert_idx) -> void

Maps each active tet's local edges onto global output vertex indices.

Stage 3. After the host has sorted and uniqued the edge keys, this kernel binds tet-local edge slots to positions in the deduplicated vertex array. One thread per active tet, binary-searching the unique key array for each of its bipolar edges. The resulting map is what lets stage 5 emit triangle indices without any further searching.

interpolate_vertices_kernel__global__#conquer3d/csrc/ops/mt.cu:277
interpolate_vertices_kernel(const uint32_t num_unique_edges, const Edge *unique_edges, const float3 *grid_vertices, const float *vert_values, const float3 *grid_normals, const float3 *grid_colors, const float iso, float3 *out_verts, float3 *out_normals, float3 *out_colors) -> void

Places one output vertex on each unique bipolar edge.

Stage 4. One thread per unique edge, linearly interpolating the crossing point $\mathbf{p} = \mathbf{p}_0 + t(\mathbf{p}_1 - \mathbf{p}_0)$ with $t = (\text{iso} - f_0) / (f_1 - f_0)$. Normals and colours defined on the grid are interpolated with the same $t$, so all attributes stay consistent with the geometry. Because each edge is visited once, every vertex is written exactly once and no atomics are needed.

Parameters
NameDescription
num_unique_edges[in] Number of unique edges, one output vertex each.
unique_edges[in] Device array of deduplicated edge keys.
grid_vertices[in] Device array of grid vertex coordinates.
vert_values[in] Device array of scalar field values at grid vertices.
grid_normals[in] Device array of per-vertex normals, or nullptr.
grid_colors[in] Device array of per-vertex colours, or nullptr.
iso[in] Isolevel being extracted.
out_verts[out] Device array of interpolated surface vertices.
out_normals[out] Device array of interpolated normals, when requested.
out_colors[out] Device array of interpolated colours, when requested.
Note

Launched with NTHREADS threads per block over a 1D grid.

Warning

The interpolation denominator $f_1 - f_0$ is non-zero for any genuinely bipolar edge, but a field with exactly equal corner values either side of the isolevel would divide by zero. Such edges are excluded upstream by the sign test.

assemble_triangles_kernel(const uint32_t num_active_tets, const uint8_t *used_tet_codes, const uint32_t *tet_edge_to_vert_idx, const uint32_t *tet_triangle_prefix_sums, uint32_t *out_triangles) -> void

Writes the triangle index triples for every active tet.

Stage 5. One thread per active tet. The sign code selects a row of the tetEdgeTable / tetTriTable triangle table, whose tet-local edge slots are translated into global vertex indices through the stage 3 map. Each tet's output begins at a precomputed prefix-sum offset, so threads write to disjoint ranges without atomics or contention.

backward_dmt_kernel__global__#conquer3d/csrc/ops/mt.cu:787
backward_dmt_kernel(const uint32_t n_verts, const Edge *unique_edges, const float *grid_values, const float3 *grid_coords, const float3 *grid_colors, const float3 *adj_verts, const float3 *adj_colors, const float iso, float *adj_values, float3 *adj_grid_colors, bool with_colors) -> void

Backpropagates vertex gradients into the scalar field and colours.

The analytical adjoint of stage 4. A vertex sits at $\mathbf{p} = \mathbf{p}_0 + t(\mathbf{p}_1 - \mathbf{p}_0)$ with $t = (\text{iso} - f_0) / (f_1 - f_0)$, so $\partial t / \partial f_0$ and $\partial t / \partial f_1$ are available in closed form and the chain rule gives the field gradient directly no finite differences, no autograd graph over the extraction itself. One thread per output vertex.

Parameters
NameDescription

grid_values[in] Device array of scalar field values at grid vertices.
grid_coords[in] Device array of grid vertex coordinates.
grid_colors[in] Device array of per-vertex colours, or nullptr.
adj_verts[in] Device array of incoming vertex position gradients.
adj_colors[in] Device array of incoming colour gradients, or nullptr.
iso[in] Isolevel used in the forward pass.
adj_values[out] Device array accumulating scalar field gradients.
adj_grid_colors[out] Device array accumulating colour gradients.
with_colors[in] Whether colour gradients are propagated.
Note

Launched with NTHREADS threads per block over a 1D grid.

Warning

Grid vertices are shared between edges, so several threads accumulate into the same slot. Writes go through atomicAdd, which makes the reduction order nondeterministic and the result bitwise non-reproducible between runs.
