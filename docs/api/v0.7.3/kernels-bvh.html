compute_morton_codes_kernel__global__#conquer3d/csrc/data_structure/bvh.cu:131
compute_morton_codes_kernel(const uint32_t num_objects, const float3 *aabb_mins, const float3 *aabb_maxs, const float3 scene_min, const float3 scene_max, uint32_t *morton_codes, int *object_ids) -> void

Assigns a Morton code to each primitive from its AABB centroid.

One thread per primitive. The centroid is normalised into the scene bounds and interleaved into a 30-bit Morton code. Sorting primitives by this code places spatial neighbours adjacently, which is the precondition for Karras's hierarchy emission the tree structure is read directly off the sorted code sequence.

Parameters
NameDescription
num_objects[in] Number of primitives $N$.
aabb_mins[in] Device array of $N$ AABB lower bounds.
aabb_maxs[in] Device array of $N$ AABB upper bounds.
scene_min[in] Lower bound of the whole scene, used to normalise centroids.
scene_max[in] Upper bound of the whole scene.
morton_codes[out] Device array of $N$ Morton codes.
object_ids[out] Device array of $N$ identity indices, permuted by the sort that follows so results can be mapped back to the caller's ordering.
Note

Launched with NTHREADS threads per block over a 1D grid.

Note

Primitives whose centroids fall within $2^{-10}$ of the scene extent share a code. Duplicates are handled during hierarchy emission by falling back to index comparison.

karras_emit_hierarchy_kernel__global__#conquer3d/csrc/data_structure/bvh.cu:181
karras_emit_hierarchy_kernel(const int num_objects, const uint32_t *morton_codes, int2 *bvh_children, int *bvh_parents) -> void

Builds the internal-node hierarchy from sorted Morton codes (Karras, 2012).

One thread per internal node, of which there are exactly $N - 1$. Each thread determines its node's range by comparing common prefix lengths with its neighbours, locates the split by binary search, and writes its two children with no synchronisation between threads at all. That independence is the whole point of the Karras construction: the entire hierarchy is emitted in a single parallel pass.

Parameters
NameDescription
num_objects[in] Number of primitives $N$.
morton_codes[in] Device array of $N$ Morton codes in ascending order.
bvh_children[out] Device array of $N - 1$ child index pairs.
bvh_parents[out] Device array of $2N - 1$ parent indices for the bottom-up pass.
Note

Launched over $N - 1$ threads; internal nodes occupy indices $[0, N-1)$ and leaves $[N-1, 2N-1)$.

Warning

Requires morton_codes to be sorted ascending. Unsorted input produces a structurally valid but spatially meaningless tree, which degrades queries to a linear scan rather than failing outright.

bottom_up_aabb_kernel__global__#conquer3d/csrc/data_structure/bvh.cu:261
bottom_up_aabb_kernel(const int num_objects, const int *object_ids, const float3 *in_aabb_mins, const float3 *in_aabb_maxs, const int *bvh_parents, const int2 *bvh_children, float3 *bvh_aabb_mins, float3 *bvh_aabb_maxs, int *atomic_flags) -> void

Propagates bounding boxes from leaves to the root.

One thread per leaf. Each seeds its own AABB, then walks towards the root merging bounds. At every internal node an atomicCAS flag decides which of the two arriving threads continues: the first exits, the second knowing both children are now final merges and proceeds. Exactly one thread therefore reaches the root, and the whole refit completes in one launch with no global barrier.

Parameters
NameDescription
num_objects[in] Number of primitives $N$.
object_ids[in] Device array mapping sorted leaf order to original indices.
in_aabb_mins[in] Device array of $N$ primitive AABB lower bounds.
in_aabb_maxs[in] Device array of $N$ primitive AABB upper bounds.
bvh_parents[in] Device array of $2N - 1$ parent indices.
bvh_children[in] Device array of $N - 1$ child index pairs.
bvh_aabb_mins[out] Device array of $2N - 1$ node lower bounds.
bvh_aabb_maxs[out] Device array of $2N - 1$ node upper bounds.
atomic_flags[inout] Device array of $N - 1$ visit flags; must be zeroed before launch.
Note

Launched with NTHREADS threads per block over a 1D grid.

Warning

atomic_flags must be cleared between builds. Stale flags let the first thread through at a node whose sibling has not finished, producing bounds that silently omit part of the subtree.

query_bvh_kernel(const uint32_t num_queries, const uint32_t num_objects, const float3 *query_mins, const float3 *query_maxs, const float3 *bvh_aabb_mins, const float3 *bvh_aabb_maxs, const int2 *bvh_children, const int *object_ids, int64_t *out_query_ids, int64_t *out_object_ids, int64_t *hit_counter, const int64_t max_capacity) -> void

Reports every BVH primitive whose AABB overlaps each query box.

One thread per query box, descending the hierarchy with a private stack and emitting a (query, object) pair for each overlapping leaf. Pairs are appended to a shared buffer through an atomic counter.

Parameters
NameDescription
num_queries[in] Number of query boxes $Q$.
num_objects[in] Number of primitives in the tree $N$.
query_mins[in] Device array of $Q$ query AABB lower bounds.
query_maxs[in] Device array of $Q$ query AABB upper bounds.
bvh_aabb_mins[in] Device array of $2N - 1$ node lower bounds.
bvh_aabb_maxs[in] Device array of $2N - 1$ node upper bounds.
bvh_children[in] Device array of $N - 1$ child index pairs.
object_ids[in] Device array mapping leaves to original primitive indices.
out_query_ids[out] Device array receiving the query index of each pair.
out_object_ids[out] Device array receiving the primitive index of each pair.
hit_counter[inout] Device counter, atomically incremented per pair.
max_capacity[in] Capacity of the output arrays.
Note

Launched with NTHREADS threads per block over a 1D grid.

Warning

Traversal uses a per-thread stack of BVH_STACK_SIZE entries held in local memory. A deeply unbalanced hierarchy can overflow it; Morton ordering keeps the tree shallow enough in practice, but pathological input remains a risk.

Warning

Output slots are claimed with a single atomic on hit_counter, so pair ordering is nondeterministic between runs. Writes stop once max_capacity is reached; compare the final counter against it to detect truncation.

Reports every overlapping pair of primitives within one BVH.

One thread per leaf, querying the tree that contains it. Self-pairs are skipped, and a pair is emitted only when the querying index is the lower of the two, so each unordered pair is reported exactly once rather than twice.

Reports every primitive whose AABB a ray enters.

One thread per ray, using the Kay-Kajiya slab test at each node and descending only into children the ray actually meets. This is a broad-phase pass: it returns candidates whose bounding boxes are hit, not confirmed surface intersections, so an exact test against the primitives is still required downstream.

Finds the primitive whose AABB is nearest to each query point.

One thread per query, tracking the best squared distance found so far and pruning any subtree whose bound already exceeds it. Unlike the other query kernels this one writes a single result per query at a fixed index, so it needs no atomics and its output is deterministic.
