dmc_count_contours_kernel(const int *voxels, const float *sdf, float iso, int num_voxels, int *contour_counts, int *edge_instance_counts) -> void

Counts the independent contours and edge instances of every voxel.

Sizing pass for Dual Marching Cubes. One thread per voxel: the corner sign code selects a row of dmc_r_pattern giving how many separate contours the cell contains, and ambiguous cases are resolved on the fly by the asymptotic decider. Cells that Dual Contouring would collapse to one vertex may hold several contours here that multiplicity is exactly what prevents pinch points and guarantees manifold output. Counting first lets the host prefix-sum exact offsets so the extraction pass writes without atomics.

Parameters
NameDescription
voxels[in] Device array of eight corner indices per voxel.
sdf[in] Device array of scalar field values at grid vertices.
iso[in] Isolevel separating inside from outside.
num_voxels[in] Number of voxels.
contour_counts[out] Device array of per-voxel contour counts, one dual vertex each.
edge_instance_counts[out] Device array of per-voxel (contour, edge) instance counts.
Note

Launched with NTHREADS threads per block over a 1D grid.

dmc_extract_dual_vertices_and_edges_kernel__global__#conquer3d/csrc/ops/dmc.cu:365
dmc_extract_dual_vertices_and_edges_kernel(const float3 *grid_vertices, const int *voxels, const float *sdf, const float *colors, const float3 *precomputed_vertices, const float3 *edge_points, const float3 *edge_normals, int num_channels, const int *vert_offsets, const int *edge_offsets, float iso, int project_iters, int num_voxels, float3 *out_vertices, float *out_colors, uint64_t *out_edge_keys, uint32_t *out_dual_vert_and_edge) -> void

Emits every contour's dual vertex and its bipolar edge keys.

One thread per voxel, writing at the offsets computed by the counting pass. For each contour the vertex starts at the centroid of its edge crossings and is then pushed onto the exact trilinear level set by project_iters Newton-Raphson steps, using the analytic trilinear value and gradient. Projection is what removes the faceting a plain centroid leaves on curved surfaces. Supplying precomputed_vertices skips both the centroid and the projection.

dmc_gather_quads_kernel__global__#conquer3d/csrc/ops/dmc.cu:574
dmc_gather_quads_kernel(const uint64_t *sorted_edge_keys, const uint32_t *sorted_dual_vert_and_edge, const float *sdf, int total_instances, int4 *out_quads, int *out_quad_count) -> void

Builds one dual face per unique shared edge.

One thread per edge instance; only the thread beginning a run of equal keys proceeds, electing a single owner per unique edge. That owner gathers the dual vertices of the contours meeting at the edge and emits a quad, or a triangle at the domain boundary. Because Dual Marching Cubes may contribute several contours from one voxel, the vertices gathered here are per-contour rather than per-cell, which is what keeps the surface manifold where cells are ambiguous.

Parameters
NameDescription
sorted_edge_keys[in] Device array of edge keys in ascending order.
sorted_dual_vert_and_edge[in] Device array of packed vertex and local edge identifiers, permuted alongside the keys.
sdf[in] Device array of scalar field values at grid vertices.
total_instances[in] Number of (contour, edge) instances.
out_quads[out] Device array receiving dual faces.
out_quad_count[inout] Device counter, atomically incremented per face.
Note

Launched with NTHREADS threads per block over a 1D grid.

Warning

Requires sorted_edge_keys to be sorted so equal keys form contiguous runs.

Warning

The output slot is claimed with atomicAdd, so face ordering varies between runs. Geometry is unaffected, but a byte-identical mesh is not guaranteed.

dmc_quad_to_triangle_kernel__global__#conquer3d/csrc/ops/dmc.cu:664
dmc_quad_to_triangle_kernel(const int4 *quads, const float3 *vertices, int num_quads, int3 *out_triangles, int *out_tri_count) -> void

Splits dual quads into triangles along the better-conditioned diagonal.

One thread per quad, choosing the split that maximises the minimum triangle angle so the output avoids slivers. Boundary faces already emitted as triangles pass through unchanged. Skipping this kernel entirely leaves a pure quad mesh.

dmc_backward_kernel__global__#conquer3d/csrc/ops/dmc.cu:727
dmc_backward_kernel(const float3 *grad_vertices, const float *grad_colors, const float3 *grid_vertices, const int *voxels, const float *sdf, const float *colors, int num_channels, const int *vert_offsets, float iso, int num_voxels, float *grad_sdf, float *grad_colors_in) -> void

Backpropagates dual vertex gradients into the scalar field and colours.

One thread per voxel, recomputing the forward pass's contour decomposition so the adjoint follows the same path. Each dual vertex's gradient is distributed to the corner values through the derivatives of its edge crossings; colour gradients follow the interpolation weights.
