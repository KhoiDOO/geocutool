trilinear_val(float u, float v, float w, const float s[8]) -> float

Trilinear interpolation of the eight corner values of a cell.

Evaluates the standard trilinear form. This is the exact field Dual Marching Cubes projects its vertices onto, so extracted geometry agrees with the interpolant the topology tables assume.

trilinear_grad__device____forceinline__#conquer3d/csrc/ops/dmc.cu:70
trilinear_grad(float u, float v, float w, const float s[8]) -> float3

Gradient of the trilinear field inside a unit cell.

Differentiates the trilinear interpolant analytically and divides by the cell spacing to return a world-space gradient. The direction is the surface normal wherever the field is a signed distance.

Parameters
NameDescription
u[in] Local coordinate along $x$, in $[0, 1]$.
v[in] Local coordinate along $y$, in $[0, 1]$.
w[in] Local coordinate along $z$, in $[0, 1]$.
s[in] The cell's eight corner values.
Returns
__device__ __forceinline__ float3

The field gradient.

Note

Paired with trilinear_val() to drive the Newton-Raphson projection of dual vertices onto the level set.

extract_cell_contours__device__inline#conquer3d/csrc/ops/dmc.cu:141
extract_cell_contours(float iso, int i_case, const float s[8], int contour_sizes[4], int contour_edges[4][12]) -> int

Decomposes a cell into its independent surface contours.

Reads the packed dmc_r_pattern row for the case, or invokes the asymptotic decider when dmc_ambig_table marks it ambiguous. Returning several contours where a cell contains disconnected surface sheets is precisely what lets Dual Marching Cubes emit multiple dual vertices and so avoid the pinch points a single-vertex-per-cell method produces.

Parameters
NameDescription
iso[in] Isolevel separating inside from outside.
i_case[in] The cell's 8-bit corner sign code.
s[in] The cell's eight corner values.
contour_sizes[out] Edge count of each contour.
contour_edges[out] Local edge indices of each contour.
Returns
__device__ int

Number of contours, 0 for a fully inside or outside cell.

Note

At most four contours fit in a cell, which bounds the output arrays.
