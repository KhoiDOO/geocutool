clampinline__device____host__static#conquer3d/csrc/maths/ops.h:62
clamp(float v, float min_val, float max_val) -> float

Confines a scalar to a range.

Scalar overload of the float3 clamp in f3x1.h. Spelling the two branches as one call keeps the intent legible where the bound is itself an expression.

Parameters
NameDescription
v[in] Value to clamp.
min_val[in] Lower bound.
max_val[in] Upper bound.
Returns
__host__ __device__ float

v confined to $[\text{min_val}, \text{max_val}]$.

Note

Ordered fmaxf(lo, fminf(hi, v)) to match the form these call sites already used. The order is irrelevant for finite input but decides which bound a NaN collapses to, so keeping it preserves the previous behaviour exactly.
