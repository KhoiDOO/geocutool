update_tags__global__#conquer3d/csrc/data_structure/kdtree.cu:129
update_tags(uint32_t *tag, int numPoints, int L) -> void

Advances every point's subtree tag by one level of the balanced KD-tree build.

The tree is built breadth-first without recursion: at level $L$ each point carries a tag naming the subtree it currently belongs to, and this kernel refines that tag after the level's partition has been applied. Pivot positions come from the left-balanced offset rule, which is what makes the finished tree complete and lets traversal address children arithmetically instead of storing pointers. One thread per point. Points already settled as pivots at shallower levels the first $2^L - 1$ entries return immediately.

Parameters
NameDescription
tag[inout] Device array of numPoints subtree tags, refined in place.
numPoints[in] Total number of points in the tree.
L[in] Level being processed, counting from the root at zero.
Note

Launched with NTHREADS threads per block over a 1D grid, once per level, so the host issues $\lceil \log_2 N \rceil$ launches in sequence.

query_kdtree_kernel__global__#conquer3d/csrc/data_structure/kdtree.cu:214
query_kdtree_kernel(const uint32_t num_queries, const uint32_t num_points, const uint32_t k, const float3 *query_points, const float3 *tree_points, const int64_t *tree_inds, float *out_dists, int64_t *out_inds) -> void

Finds the $k$ nearest neighbours of every query point.

One thread per query, each performing an independent stackless descent of the balanced tree via query_kdtree_loop. Because the tree is complete, child indices are computed arithmetically and the traversal needs no explicit stack only a small insertion-sorted priority queue held in registers.

Parameters
NameDescription
num_queries[in] Number of query points $N$.
num_points[in] Number of points in the tree $M$.
k[in] Neighbours to return per query; must not exceed MAX_K.
query_points[in] Device array of $N$ query coordinates.
tree_points[in] Device array of $M$ coordinates in KD-tree order.
tree_inds[in] Device array of $M$ permutation indices mapping tree order back to the caller's original ordering.
out_dists[out] Device array of $N \times k$ squared distances, ascending per query.
out_inds[out] Device array of $N \times k$ original-order point indices; unfilled slots are $-1$.
Note

Launched with NTHREADS threads per block over a 1D grid.

Warning

The priority queue is sized by the compile-time constant MAX_K so it stays in registers. Raising MAX_K increases register pressure on every thread and can spill to local memory, costing far more than the extra neighbours are worth.

Warning

Traversal is data dependent, so warps diverge when their queries prune different branches.
