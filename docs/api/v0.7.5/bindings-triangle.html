conquer3d._C.Triangle.test_point_on_tria_plane(p, eps=1e-5f)

Tests whether a point lies on the triangle's supporting plane.

Evaluates the absolute point-to-plane distance $|\mathbf{n} \cdot (\mathbf{p} - \mathbf{v}_0)|$ against a tolerance, where $\mathbf{n}$ is the unit face normal. This is a coplanarity test only; it says nothing about whether the point falls within the triangle's bounds.

Parameters

Returns
bool

True if the point is within eps of the supporting plane.

Example
>>> tri.test_point_on_tria_plane(torch.tensor([0.2, 0.3, 0.0]))
conquer3d._C.Triangle.test_point_inside_on_tria_planemethod#conquer3d/csrc/binds/primitive/triangle.cpp:230
conquer3d._C.Triangle.test_point_inside_on_tria_plane(p)

Tests whether a coplanar point falls inside the triangle.

Solves for the barycentric coordinates $(u, v, w)$ of the point against the edge vectors and reports whether all three are non-negative. The point is assumed to already lie on the supporting plane -- a point far off the plane projects onto it and may still report True, so pair this with test_point_on_tria_plane (or use test_point_inside) for a full containment test.

Parameters
NameTypeDescription
ptorch.Tensor(3,) float32 query point, assumed coplanar.
Returns
bool

True if the point lies within the triangle, edges and vertices included. False for degenerate triangles, whose barycentric denominator collapses below 1e-8.

Example
>>> tri.test_point_inside_on_tria_plane(tri.compute_centroid())

conquer3d._C.Triangle.test_point_inside(p, eps=1e-5f)

Tests whether a point lies on the triangle itself.

The full containment predicate: the point must be coplanar within eps and fall inside the triangle's barycentric bounds. Equivalent to test_point_on_tria_plane followed by test_point_inside_on_tria_plane, short-circuiting on the cheaper plane test first.
