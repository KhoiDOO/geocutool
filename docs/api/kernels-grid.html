get_active_voxel_ids_from_depth_kernel(const int num_pixels, const float *depth_image, const float4x4 c2w, const float3x3 intrinsics_inv, const int image_width, const int image_height, const float3 grid_min, const float3 grid_max, const int3 res, int64_t *out_voxel_ids, unsigned long long *valid_counter, bool activate_neighbor, float trunc_margin) -> void

Back-projects a depth map into the voxel indices its surface touches.

One thread per pixel. Each unprojects its depth sample through the inverse intrinsics into camera space, transforms to world space, and quantises the result to a voxel index carving a surface band directly out of a depth image without ever allocating the dense volume. With activate_neighbor set, the $3 \times 3 \times 3$ neighbourhood is activated too, widening the band so later extraction has samples on both sides of the surface.

Parameters
NameDescription
num_pixels[in] Number of depth samples $W \times H$.
depth_image[in] Row-major depth buffer.
c2w[in] Camera-to-world transform.
intrinsics_inv[in] Inverse camera intrinsics.
image_width[in] Depth image width in pixels.
image_height[in] Depth image height in pixels.
grid_min[in] World coordinate of the grid's lower corner.
grid_max[in] World coordinate of the grid's upper corner.
res[in] Per-axis voxel resolution.
out_voxel_ids[out] Device array receiving activated linear voxel indices.
valid_counter[inout] Device counter, atomically incremented per emission.
activate_neighbor[in] Whether to also activate the surrounding 26 voxels.
trunc_margin[in] Band half-width in world units.
Note

Launched with NTHREADS threads per block over a 1D grid.

Note

Pixels with non-positive depth are treated as missing and skipped.

Warning

Output order is nondeterministic because slots are claimed by atomics, and the same voxel may be emitted by many pixels. Callers must sort and deduplicate.

quantize_vertices_to_voxel_ids_kernel__global__#conquer3d/csrc/data_structure/grid.cu:157
quantize_vertices_to_voxel_ids_kernel(const float3 *vertices, int num_vertices, float3 grid_min, float3 grid_spacing, int3 num_cells, int64_t *out_voxel_ids) -> void

Maps each vertex to the linear index of the voxel containing it.

One thread per vertex, computing $\lfloor (\mathbf{v} - \mathbf{g}_{min}) / \mathbf{s} \rfloor$ and flattening the result in $x$-major order. Vertices outside the grid are dropped rather than clamped, so out-of-bounds geometry cannot fold onto the boundary and create phantom occupancy.

Parameters
NameDescription
vertices[in] Device array of num_vertices coordinates.
num_vertices[in] Number of vertices.
grid_min[in] World coordinate of the grid's lower corner.
grid_spacing[in] Per-axis voxel size.
num_cells[in] Per-axis cell counts.
out_voxel_ids[out] Device array of num_vertices linear voxel indices.
Note

Launched with NTHREADS threads per block over a 1D grid.

Note

Indices are int64_t; a $1024^3$ grid exceeds the 32-bit range.

create_voxel_cloud_corners_kernel__global__#conquer3d/csrc/data_structure/grid.cu:248
create_voxel_cloud_corners_kernel(const float3 *vertices, int num_vertices, float3 voxel_spacing, float3 *out_corners) -> void

Expands each voxel centre into its eight corner coordinates.

One thread per voxel centre, writing eight corners at a fixed stride so the output is a dense (N, 8, 3) array requiring no compaction. Corner order follows the library's counter-clockwise convention, matching the topology tables the extraction kernels index into.

Parameters
NameDescription
vertices[in] Device array of num_vertices voxel centre coordinates.
num_vertices[in] Number of voxel centres.
voxel_spacing[in] Per-axis voxel size; corners sit half a spacing from the centre.
out_corners[out] Device array of num_vertices * 8 corner coordinates.
Note

Launched with NTHREADS threads per block over a 1D grid.

Note

Corners shared between neighbouring voxels are duplicated; deduplicate downstream if a welded vertex set is required.
