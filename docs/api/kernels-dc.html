compute_dual_vertices_kernel__global__#conquer3d/csrc/ops/dc.cu:136
compute_dual_vertices_kernel(const float3 *grid_vertices, const int *voxels, const float *sdf, const float3 *grid_normals, float iso, int num_voxels, float3 *dual_vertices, int *voxel_is_active, int *bipolar_edge_counts) -> void

Solves one dual vertex per active voxel by minimising a quadratic error function.

The heart of Dual Contouring. One thread per voxel. Each bipolar edge contributes a plane through its crossing point with the local surface normal, and the vertex is placed at the point minimising $\sum_i (\mathbf{n}_i \cdot (\mathbf{v} - \mathbf{p}_i))^2$. Because the planes reconstruct the surface's own tangent structure, the minimiser lands exactly on creases and corners which is why Dual Contouring keeps mechanical CAD edges that vertex-on-edge methods round away. The normal matrix is diagonalised by cyclic Jacobi entirely in registers, and its pseudoinverse is truncated at a relative eigenvalue tolerance so that under-constrained cells fall back towards the cell centroid instead of shooting off along a null direction.

Parameters
NameDescription
grid_vertices[in] Device array of grid vertex coordinates.
voxels[in] Device array of eight corner indices per voxel.
sdf[in] Device array of scalar field values at grid vertices.
grid_normals[in] Device array of per-vertex normals, or nullptr to derive them from the trilinear field gradient.
iso[in] Isolevel separating inside from outside.
num_voxels[in] Number of voxels.
dual_vertices[out] Device array of one solved vertex per voxel.
voxel_is_active[out] Device array of per-voxel activity flags.
bipolar_edge_counts[out] Device array of per-voxel bipolar edge counts.
Note

Launched with NTHREADS threads per block over a 1D grid.

Note

The solved vertex is clamped to the cell's bounding box, so a badly conditioned QEF can never place geometry outside the voxel that produced it.

Warning

The Jacobi solve is register resident. Raising the sweep count increases register pressure and can spill to local memory, which costs far more than the extra precision is worth.

emit_bipolar_edges_kernel(const int *voxels, const float *sdf, const int *edge_offsets, float iso, int num_voxels, uint64_t *out_edge_keys, uint32_t *out_voxel_and_edge) -> void

Emits a sortable key for every (voxel, bipolar edge) instance.

One thread per voxel, writing a 64-bit key identifying the shared grid edge alongside the voxel and local edge that produced it. Sorting these keys groups the (up to four) voxels around each edge together, which is what lets the next stage build a dual face from an edge's incident cells without any neighbour lookup structure.

gather_dual_quads_kernel__global__#conquer3d/csrc/ops/dc.cu:300
gather_dual_quads_kernel(const uint64_t *sorted_edge_keys, const uint32_t *sorted_voxel_and_edge, const float3 *grid_vertices, const float *sdf, const float3 *dual_vertices, const int *voxel_to_compact_idx, int total_instances, int4 *out_quads, int *out_quad_count) -> void

Builds one dual face from the voxels surrounding each shared edge.

One thread per key instance, but only the thread at the start of each run of equal keys proceeds a lightweight way to elect one owner per unique edge without a separate compaction pass. That owner collects the dual vertices of the incident voxels and emits a quad, or a triangle where the edge lies on the domain boundary and only three cells exist. Winding is chosen from the sign of the edge so faces are consistently oriented.

Parameters
NameDescription

sorted_voxel_and_edge[in] Device array of packed voxel and local edge identifiers, permuted alongside the keys.
grid_vertices[in] Device array of grid vertex coordinates.
sdf[in] Device array of scalar field values at grid vertices.
dual_vertices[in] Device array of per-voxel solved vertices.
voxel_to_compact_idx[in] Device array mapping voxel index to compacted vertex index.

Requires sorted_edge_keys to be sorted, otherwise runs are not contiguous and faces are emitted several times or not at all.

quad_to_triangle_kernel(const int4 *quads, const float3 *compact_vertices, int num_quads, int3 *out_triangles, int *out_tri_count) -> void

Splits dual quads into triangles along the shorter diagonal.

One thread per quad. The diagonal is chosen by comparing the two candidate splits, which keeps the resulting triangles better conditioned than always cutting the same way. Faces already emitted as boundary triangles marked by a repeated final index are passed through unchanged.

Compacts per-voxel dual vertices and colours into dense output arrays.

One thread per voxel; inactive voxels exit immediately. Active ones copy their vertex to the slot given by the prefix-summed index map and, when colours are present, trilinearly interpolate the field colour at the dual vertex position. Writes target disjoint slots, so no atomics are required.

backward_dual_contouring_kernel__global__#conquer3d/csrc/ops/dc.cu:551
backward_dual_contouring_kernel(const float3 *grad_verts, const float *grad_colors, const float3 *grid_vertices, const int *voxels, const float *sdf, const int *voxel_is_active, const int *voxel_to_compact_idx, float iso, int num_voxels, int num_channels, float *grad_sdf, float *grad_colors_in) -> void

Backpropagates dual vertex gradients into the scalar field and colours.

One thread per voxel. The incoming gradient on a dual vertex is redistributed across the bipolar edges that constrained its QEF, each contributing through the derivative of its crossing point with respect to the two corner values. Colour gradients follow the trilinear interpolation weights used in the forward pass.

Warning

Grid vertices are shared between voxels, so accumulation goes through atomicAdd and the reduction order and hence the last bits of the result varies between runs.

Warning

This adjoint covers the QEF solution's dependence on the edge crossings, not the discrete choice of which voxels are active. Gradients are therefore undefined exactly at topology changes, where a voxel switches between active and inactive.

detect_active_voxels_kernel__global__#conquer3d/csrc/ops/dc.cu:626
detect_active_voxels_kernel(const int *voxels, const float *sdf, float iso, int num_voxels, int *voxel_is_active, int *bipolar_edge_counts) -> void

Flags voxels the surface crosses and counts their bipolar edges.

Cheap first pass. One thread per voxel: a voxel is active when its eight corner signs are not all equal, and the number of bipolar edges is recorded so the host can prefix-sum exact output offsets before any heavy work runs. Separating this from the QEF solve means the expensive stage only ever launches over active voxels.
