solve_pgs_pair_tangency_radius(const float3 &mean, const float3 &normal, const float *covi, const float3 &neighbor_mean, const float3 &neighbor_normal, float &out_iso) -> bool

Solves the exact pairwise tangency contact radius between two adjacent planar Gaussians.

Finds the intersection line of two tangent planes $n_i, n_j$ and minimizes the Mahalanobis distance along the line to find the critical contact isosurface radius $r^2$.

Parameters
NameDescription
mean[in] First Gaussian centroid $\mu_i$.
normal[in] First Gaussian normal axis $n_i$.
covi[in] First Gaussian inverse covariance $\Sigma_i^{-1}$.
neighbor_mean[in] Second Gaussian centroid $\mu_j$.
neighbor_normal[in] Second Gaussian normal axis $n_j$.
out_iso[out] Computed tangency radius squared.
Returns
__device__ __forceinline__ bool

bool True if planes intersect non-parallelly and a valid tangency radius exists.
