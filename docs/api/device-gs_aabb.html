test_gs_intersect_voxel_edge(const float3 &mean, const float *covi, const float3 &vx_ab_min, const float3 &vx_ab_max, const float iso) -> bool

Tests whether a Gaussian's isosurface crosses any edge of a voxel.

Works in the Gaussian's local frame, where the ellipsoid becomes a unit sphere and the test reduces to a quadratic along each edge. One of the three cases making up the full voxel test.
