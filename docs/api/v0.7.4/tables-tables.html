dc_edge_quadrant__constant__static#conquer3d/csrc/ops/dc_data.h:70
dc_edge_quadrant: __constant__ int

Cartesian quadrant slot assigned to each of the 12 local edges.

Dual methods place vertices per edge rather than per cell, so each edge must map deterministically to one of four quadrant slots. Because adjacent cells agree on this mapping, the dual quad around a shared edge is assembled consistently from all four incident cells. Slots 0-3 must walk the four incident cells counter-clockwise about the edge's own positive axis, and all three edge families must agree on that handedness otherwise the faces of one family are wound backwards relative to the rest and the extracted mesh has inconsistent normals. The right-handed plane perpendicular to each axis is $(Y, Z)$ for $+X$, $(Z, X)$ for $+Y$ and $(X, Y)$ for $+Z$; note that $+Y$ pairs with $(Z, X)$ and not $(X, Z)$, which is the easy mistake here.

dmc_ambig_table__constant__static#conquer3d/csrc/ops/dmc_data.h:102
dmc_ambig_table: __constant__ unsigned char

Maps each corner-sign case to its topological equivalence class representative.

Entries carrying the sentinel DMC_AMBIGUOUS (254) mark cases whose face or interior connectivity cannot be settled from corner signs alone and must be resolved at runtime by the asymptotic decider. All other cases index a canonical representative, collapsing the 256 configurations onto the far smaller set of distinct topologies.

triTable__constant__static#conquer3d/csrc/ops/mc_data.h:102
triTable: __constant__ int

Edge triples forming the triangles of each corner-sign case.

Each row lists edge indices in groups of three, one group per triangle, wound consistently for outward-facing normals and terminated by -1. At most five triangles fit in a cell, so 15 entries plus the terminator bound the row width.

dmc_r_pattern__constant__static#conquer3d/csrc/ops/dmc_data.h:370
dmc_r_pattern: __constant__ char

Packed contour patterns for all 256 corner-sign cases.

A flat $256 \times 17$ byte array. Row $c$ begins at offset $17c$; its first entry is the number of contours in the cell, after which each contour is stored as a length followed by that many edge indices, with unused entries set to -1. Flattening keeps the whole table at 4352 bytes so it stays resident in constant memory and is broadcast to every thread in a warp at full speed.

dmc_e_face: __constant__ unsigned short

Bit-packed edge indices of each cube face, for the on-the-fly asymptotic decider.

Face order is $-Z, +Z, -Y, +Y, -X, +X$. Each 16-bit word packs the face's four edge indices into 4-bit fields, so the decider unpacks a face with shifts and masks rather than an extra constant-memory read.
